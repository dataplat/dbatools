# dbatools Test Style Guide

This document used to carry its own copy of the test style rules, and had drifted from the copy in
`.github/prompts/style.md` as well as from the tree - its examples still used
`$TestConfig.instance2` and `$TestConfig.instance3`, which no test file uses any more.

**The test standards now live in one place: [tests/CLAUDE.md](../../tests/CLAUDE.md).**

For converting a Pester v4 file, see [.github/prompts/migration.md](../../.github/prompts/migration.md).
